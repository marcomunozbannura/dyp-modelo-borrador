# Modelo borrador — Control de Taller

Demostración navegable de un sistema de control de flujo de taller, construida por
**Arttmize SpA** para Automotora DyP.

**Es un modelo, no un sistema en operación.** No hay base de datos ni servidor detrás: todo corre
en el navegador de quien lo abre y los datos son de demostración. Nada de lo que se escriba aquí
sale del equipo, y basta con borrar los datos del sitio para dejarlo como nuevo.

## Cómo probarlo

Se entra con una cuenta por puesto de trabajo. Las claves están a la vista en la propia pantalla de
ingreso, con un enlace que entra de un clic.

Vale la pena entrar con **cuentas distintas** y comparar: cada puesto ve pantallas distintas y, aun
dentro de la misma pantalla, filas distintas. Un pintor ve sólo los vehículos que le asignaron; la
administración los ve todos.
